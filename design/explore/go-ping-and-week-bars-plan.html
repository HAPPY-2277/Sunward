SECTION 01

GO 按钮外脉冲环提亮

现状是「1dp 描边 + 18% 墨色」，压在饱和琥珀 hero 卡上几乎看不见。改法：描边加粗到 1.5dp、 颜色提到 85% 墨色（ink_85），仍然是「一圈细描边向外扩散并淡出」的形制，不动动画本身。
四轮过程：第 1 轮 40% 墨（仍嫌淡）→ 第 2 轮出 6 组候选 → 第 3 轮用户拍板 「C 的深墨方向、但不透明度 85%、描边 1.5dp」→ 第 4 轮定稿即本文与代码现状。

为什么提亮墨色而不是换成奶油色。 脉冲环落在琥珀 hero 卡（#EF9F27）上，用奶油色描边反而会消失在亮底里； 墨色既能提亮轮廓，又与 design/explore/component-styles.html:240 的 rgba(44,44,42,.18) 墨色系保持同源。同时保留「细描边」形制， 不重演历史上「实心圆盘 + 描边」放大后变成一圈甩不掉黑边的老问题。

定稿为 85% 墨（ink_85）：色相比实心墨只差 15%，肉眼几乎等同， 但保留了「淡墨描边」的质感，不会像 100% 实墨那样与 GO 墨盘糊成一团。 描边粗细按用户拍板保持 1.5dp（沿用第 1 轮），不跟着 C 方案加粗到 2dp。

怎么读这些数字 · 我的建议 对比度 = 环的实际颜色（颜色 alpha 叠在琥珀底上）与琥珀底 #EF9F27 的亮度比，WCAG 公式。 峰值 对应 scale 1.00（环刚离开墨盘、动画 alpha 仍是 1）；中段 对应 scale 1.45（动画 alpha 已降到 0.55）。 两者差得远，是因为有效不透明度 = 颜色 alpha × 动画 alpha：动画自己一直在把环淡掉， 颜色再深也会被乘一遍 —— 这就是「明明换了颜色还是偏淡」的原因，也是本轮不把淡出节奏当变量的原因。

建议 C（实心墨 100% + 2dp）：峰值 6.44:1，是唯一一眼能看清的档位，且不需要新增令牌； 环与 GO 墨盘同色，视觉上像圆盘自己的回声，不会显得脏。 保守选 B（墨 75% + 2dp）：峰值 3.95:1，越过 3:1 参考线但仍保留「淡墨」气质，代价是要在 colors.xml 增一个 ink_75。 C 与 D 的差别只在描边粗细（对比度相同），D 更粗更实、离「细描边」形制更远。 E 深琥珀最贴主题气质但数值低于 A，F 近白奶只留作对照。

→ 最终拍板：取 C 的深墨方向，不透明度定 85%、描边保持 1.5dp （即上表「★ 定稿」行）。理由与落地清单见下方第三轮小节。
拍板结论（2026-10-28）。 用户选 C（实心墨 100% + 2dp），但把不透明度改成 85%、描边改回 1.5dp —— 即「取 C 的深墨方向，不取 C 的粗描边」。定稿见下方第三轮小节。

为什么 85% 而不是 100%：85% 与 100% 肉眼几乎同深（差 15% 墨）， 但 100% 实墨会与 GO 墨盘糊成一体、失去「一圈淡墨描边向外扩散」的心智； 85% 保留描边质感，同时把峰值对比度从第 1 轮的 1.97:1 提到 4.87:1 —— 已越过 3:1 非文本参考线。 描边保持 1.5dp：粗描边在 scale 2.0 时会变成一条实边，与历史上「甩不掉的黑边」问题同源。

落地改动（已在 2026-10-28 提交）：colors.xml 新增一行 ink_85（沿用 ink_06…ink_60 的 alpha 阶梯命名法）； bg_go_ping.xml 的 stroke 颜色改 @color/ink_85、宽度保持 1.5dp； design/prototype/activity.html 第 58 行改 border-[#2C2C2A]/[0.85] border-[1.5px]。

落地后的实拍：模拟器（local 变体）重装后连拍 8 帧，第 6 帧刚好抓到扩散中段的弧线 —— 弧线在琥珀底上清晰可辨，入库为 docs/screenshots/132-go-ping-ink85.png。 仍不动的：动画参数（2.4s / cubic-bezier(0,0,.2,1) / scale 1→2 / alpha 1→0）。

排布算法（改后）

// 七列等分铺满卡片内容区宽度：列宽 = 可用宽 ÷ 7
// 柱子在列内居中，间隙恒定 4dp
val columnWidth = width / 7f
val barWidth = (columnWidth - barGap)
        .coerceAtLeast(minBarWidth)
fun centerX(i: Int) =
        columnWidth * i + columnWidth / 2f

尺寸换算

卡片左右各 20dp margin + 20dp padding = 80dp，故视图宽 = 屏宽 − 80dp。 现状 7×20 + 6×4 = 164dp，在 393dp 屏上只占 52%，左右各空 74.5dp； 改后柱子几乎贴到卡片描边内侧，视觉上连成一整条周色带。

保持不变的部分。 柱高口径仍是「当日运动时长（分钟）」，按本周已发生值最大值归一化； 今日列仍是「衬底 + 琥珀实心日期圆 + 柱顶 X 分 chip」三件套； 未来日仍留空不画假柱；进度条与脚注仍是「动了 X 天」口径，不含任何欠账措辞。
