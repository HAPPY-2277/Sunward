### 为什么必须拆变体（关键决策）

高德 3D 地图的 native 库只有 `arm64-v8a` / `armeabi-v7a`。把它打进主变体后，APK 变成 ARM-only，**x86_64 模拟器直接报 `INSTALL_FAILED_NO_MATCHING_ABIS` 装不上** —— 这意味着后面 M4–M7 我完全没法自测。

因此拆成两个变体，两边各自提供 `provideMapLayer()` / `providePrivacyGate()` 的实现（`src/amap` 与 `src/local`），主源码集只依赖接口，两种变体都能编译。

### 风险（最容易踩的坑）

> **高德 Key 绑定「包名 + 签名 SHA1」**。本工程包名 `com.runclub.android`，
> debug 签名 SHA-1 = `cfd6bad792fa17aca4d7ea8206c6c48f6bcec59a`。
> 如果你在控制台创建 Key 时填的包名/SHA1 与上面不一致，地图会**白屏**（日志里通常是 `INVALID_USER_SCODE`）。
> 这种情况下把控制台里 Key 的 Package Name 改成 `com.runclub.android`、SHA1 改成上面这串即可。
>
> 另外：真机上若看到地图但**位置偏了几百米**，说明用的是 WGS-84 直传——本次已做 GCJ-02 转换，理论上不会偏。
