# 修复轮 · 桌面式切页与左右滑手势（分支 `fix/home-live-ux`）

**执行日期**：2026-10-27　**状态**：✅ local 变体模拟器实测通过（含手势四分支与位移复位），⏳ 待用户验收

> 用户反馈上一轮的切页「仍然不够平滑，需要类似手机桌面的切换效果」，并要求补一个左右滑动切页的基础手势。按用户指定这一轮只做两次提交：`fix`（动画）+ `feat`（手势）。
> 四项实现选型均按用户确认的推荐方案：保留两个 Activity 做同步整屏平移、手势只用在首页↔记录页、去掉 48dp 边缘限制统一成一种手势、位移或速度任一达标就切页。

### 1. 切页动画：视差改为桌面式同步整屏平移（fix）

上一轮的 `slide_out_left` / `slide_in_left` 只让旧页面退开 **25% 屏宽**，新页面盖在上面滑进来，看着像两张纸叠着移动，而不是「一排页面在推」。这一轮把两个值都改成整屏：

| 动画 | 旧 | 新 |
|---|---|---|
| `slide_out_left`（正向切页时退场的旧页面） | `0 → -25%p` | `0 → -100%p` |
| `slide_in_left`（返回时从左边回来的下页） | `-25%p → 0` | `-100%p → 0` |

`slide_in_right`（`100%p → 0`）与 `slide_out_right`（`0 → 100%p`）本来就是整屏，未改。

四个动画共用同一个 `@integer/nav_anim_duration_ms`（280ms）与同一个 `decelerate_interpolator`，所以两个窗口在任意时刻的位移互补：旧页右边缘始终等于新页左边缘，中间既不留缝也不重叠，视觉上就是一整排在推。仍然**不加 alpha 渐隐**（窗口背后是黑色任务背景，淡出会闪一下黑）。

### 2. 左右滑动切页手势（feat）

新增 `ui/PageSwipeRule.kt`（纯 Kotlin 判定规则，可在 JVM 上单测）与 `ui/PageSwipeHelper.kt`（Android 触摸管道），取代上一轮的 `ui/SwipeBackHelper.kt`（已 `git rm`）；两页各自接线：

| 页面 | 手势 | 结果 |
|---|---|---|
| 首页 | 整屏任意处向左拖 | 翻到记录页 |
| 记录页 | 整屏任意处向右拖 | 翻回首页 |
| 两页 | 往没有页面的一侧拖、或竖向滚动 | 不抢手势，事件交还列表 |

- **起手**：横向位移超过 `touchSlop`、方向正确、且横向 > 竖向 × 1.5（斜着滚列表不误触）；抢手势前给子 View 补发一次 `ACTION_CANCEL`，否则列表以为手指还在它身上。
- **切页**：拖过 25% 屏宽 **或** 甩动速度 ≥ 800dp/s 且方向正确，任一达标即切；否则 180ms 回弹。跟手位移只往有页面的一侧走（`clampDrag`）。
- 按用户选型**去掉了上一轮的 48dp 左边缘限制**，边缘与全宽行为一致，只保留一种手势；系统返回键照旧走同一套动画。
- 页面平移露出的就是窗口背景 `bg_base`，所以**去掉了上一轮垫在页面下的深色 scrim**：少一层 View，也避免松手瞬间 `#050705 → #080B08` 的色差。
- 切页成功时刻意**保留当前位移**直接 `startActivity` / `finish`，让窗口动画在这段位移上接着把页面送出去（先归零画面会跳一下）。
- 首页压在记录页下面不会被销毁，所以 `attach()` 里注册 `ON_RESUME` 把 `translationX` 归零——否则从记录页返回首页时整页会一直偏着。
- 实时页与成绩页不加手势：实时页整屏是地图与大数据字，误触代价高；成绩页不在底部导航体系里，左右方向没有对应页面。

### 测试

- 新增 `PageSwipeRuleTest`（13 个用例）：两页各自的起手方向、反向拖不起手、位移不过 `touchSlop` 不起手、斜着滚列表不算手势（`-40,-40` 不起手 / `-100,-60` 起手）、竖向滚动放弃手势、跟手位移只往有页面的一侧、拖过 25% 才切、位移不够但甩够快也切、反方向的速度不算甩。
- 全量 `clean testLocalDebugUnitTest assembleLocalDebug assembleAmapDebug`：**85 个用例通过（failures=0、errors=0，11 个测试类）**，上一轮 72 → 本轮 85；两个变体均构建成功。
- 甩动那一条只能靠单测覆盖：模拟器用 `input swipe` 注入的速度与真实手指不是一回事，测不准阈值。

### 已知取舍

拖动切页时，两页之间会短暂露出与位移等宽的一条窗口背景（`bg_base`，与页面底色几乎同色），窗口动画结束即消失；点击底部导航切页没有拖拽位移，是完全无缝的。评估过的替代方案都更差：松手瞬间把位移归零会有一帧约 276px 的反向跳变；先回弹再切页要多等 180ms；要做到真正无缝得给记录页加透明主题（`windowIsTranslucent`），会影响所有进入路径且低版本表现不一致。
