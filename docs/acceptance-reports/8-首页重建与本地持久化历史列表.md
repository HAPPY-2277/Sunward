### 关键实现

| 点 | 做法 |
|---|---|
| 存储 | 手写 `SQLiteOpenHelper`，两张表（run / track_point）+ 索引；插入走**单一事务** |
| 批量插入 | 预编译 statement，避免每点一次 SQL 往返 |
| 级联删除 | 事务内先删 track_point 再删 run |
| 派生指标 | 每公里分段**不入库**，由原始轨迹点重算（避免删记录后统计不同步） |
| 周窗口 | 周一起算；按记录**开始时间**归属；跨月跨年正确 |
| 轨迹存储 | 一律 WGS-84，接高德时只在渲染层转 GCJ-02 |

### 本阶段修掉的 5 个问题

| # | 问题 | 根因 | 修复 |
|---|---|---|---|
| 1 | 首页 hero 卡被撑得过高 | 装饰圆环放在竖向 LinearLayout 里，各占一行 | 改成 FrameLayout 叠层，绝对定位不占空间 |
| 2 | GO 按钮变成圆角方块 | ping 动画只缩放 `scaleX`，把圆形拉成椭圆 | 同时设置 `scaleY`，X/Y 等比 |
| 3 | 记录页一打开就崩 | `activity_records.xml` 8 处 TextView 只写了 `style=` 没写 `layout_width`（样式里不含尺寸） | 补齐尺寸；并写了 `tools/fix_layout_size.py` 做批量检查 |
| 4 | 记录没存进库且**查不到任何线索** | `runCatching` 把异常静默吞了 | 改成 try/catch + `Log.i/e`，错误可见 |
| 5 | 缩略大图的起点圆盖住整条轨迹 | 轨迹占满画布，标记半径固定 | 轨迹只占 60% 画布，标记半径按画布大小自适应 |
