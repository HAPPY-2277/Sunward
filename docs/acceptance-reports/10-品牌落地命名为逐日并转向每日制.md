# M8 · 品牌落地：命名为「逐日」并全面转向每日制

**执行日期**：2026-10-24　**状态**：✅ 执行完成，⏳ 待用户验收

> 依据用户的设计初心（给家人做、强调每日运动），产品定名 **逐日**，
> 并把整套指标体系从「公里目标制」改为「每日制」。理念全文见 [产品理念.md](../产品理念.md)。

### 1. 改名

| 位置 | 改前 | 改后 |
|---|---|---|
| 启动器名称 | RUN CLUB | **逐日** |
| 首页顶栏 | Run Club | **逐日** |
| 记录页顶栏 | Run Log | **逐日 · 记录** |
| 记录页副标题 | 每一步，都值得被记住。 | **每天一点，一年很远。** |

包名 `com.runclub.android` **保持不变**（高德 Key 绑定包名+签名，改动会导致地图白屏）。

### 2. 从「公里目标」改为「每日制」

| 指标 | 改前 | 改后 |
|---|---|---|
| 首页本周进度 | 23.6 / 30 KM（公里目标） | **动了 5 天**（天数） |
| 首页进度条文案 | 还差 16.0 km 达标 | **已动 5 天，共 7 天** |
| 报告页主数字 | 累计里程 60.5 KM | **动过的天数 5 天** |
| 报告页进度 | 距 30 km 目标还差 6.4 km | **已动 5 天，共 7 天** |
| 「较上期」 | 比里程 ±% | **比动过的天数 ±%** |
| 月度卡主数字 | 本月累计 60.5 KM | **本月动过 10 天** |
| 「连续运动」 | 连续 N 天（断了归零） | **累计运动 N 天**（永不归零） |

### 3. 去除欠账式表达

全站已无「还差 / 达标 / 目标进度」措辞。空态与鼓励语改为：

| 场景 | 文案 |
|---|---|
| 本周一天没动 | 今天还没动，出去走走吧 |
| 动了一部分 | 明天也出门走走？ |
| 七天都动了 | 这七天都动过了，很好 |
| 进度条 | 已动 N 天，共 M 天 |

### 4. 术语口语化（31 处）

| 改前 | 改后 |
|---|---|
| 配速 / 平均配速 | 每公里约 |
| 分段配速 | 每公里用时 |
| 训练已完成 | 今天也动了 |
| 训练构成 | 运动构成 |
| 轻松跑 / 节奏跑 / 长距离 | **慢走 / 常跑 / 远足** |
| 次训练 | 次运动 |
| 图表图例「配速」 | 快慢 |

**分类规则同步调整**（原来按配速分，现在按距离分，家人更好理解）：

- 慢走：单次 < 2.5 km
- 远足：单次 ≥ max(8 km, 平均单次 × 1.5)
- 常跑：其余

### 5. 字号可读性

原全站有 **108 处 8sp / 9sp / 10sp** 的标签，长辈看不清。现全部提升到 **11sp 以上**：

```
改前：8sp×21  9sp×47  10sp×16  11sp×24
改后：11sp×108（无低于 11sp 的字号）
```

工具：`tools/bump_font_size.py`（单次最多 +2sp，可重复执行，避免一次拉太大撑破布局）。

### 6. 顺手修掉的问题

| # | 问题 | 处理 |
|---|---|---|
| 1 | 「较上期」一处注释写着「比天数」，代码却在比里程 | 改为真的按天数比，并补了 3 个单测锁住 |

### 7. 测试

**59 个单元测试全绿**（新增 6 个锁定新口径）：

- `周进度按动过的天数计算`：只跑 0.6 km 但动 1 天 → 1/7 = 14%，而不是 0.6/30
- `同一天跑两次只算一天`：runCount=2 但 activeDays=1
- `七天全都动过时进度为 100`
- `与上周对比按动过的天数算而不是公里`：里程降 85% 但天数翻倍 → 显示 +100%
- `运动构成三类名称是口语化的`：断言不含「节奏跑 / 长距离 / 轻松跑」
- `没有任何一条观察文案使用训练术语`：遍历周/月/年，断言不含「配速/达标/还差/训练」
