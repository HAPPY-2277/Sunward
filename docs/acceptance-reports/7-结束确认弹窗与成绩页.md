### 修掉的真 bug

**弹窗与成绩页的「平均配速」显示 `--'--"`**。原因：`averagePaceSecPerKm` 用了 `accumulatedMs`，而这个值只在暂停/结束时才累加，跑步途中恒为 0 → 判定为「无有效配速」。改成 `averagePaceSecPerKm(nowMs)` 用实时耗时，并补了单测 `平均配速使用实时耗时`。

### 按计划隐藏的卡片（无真实数据源，不展示假数字）

原型里的「累计爬升 / 平均步频 / 平均心率 / 步数 / 连续运动」本次没有数据来源（无气压计、无 BLE、无计步传感器接入），按计划附录 C 的默认方案隐藏。成绩页只保留有真实数据的部分：总距离、用时、平均配速、消耗、路线、分段配速、配速曲线、点评。
