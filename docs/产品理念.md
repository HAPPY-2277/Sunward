# 逐日 · SUNWARD

> 本文是这个 App 的**判断依据**。以后遇到「这个功能要不要做 / 这句话该怎么写」，
> 先回来对一遍这四条，而不是对一遍原型的截图。

## 零、名字

**逐日**（zhú rì）· **SUNWARD**

「逐」是走之底（辶）——它的本义就是「追」，字形本身就是「走着追」。日既是太阳，也是日子。
所以「逐日」同时是：**一天一天地**、**追着每一个日出**。

英文名 **SUNWARD** 意为「向着太阳」：`sun` 对应日，`ward` 对应趋向，
与中文近乎逐字对译。品牌色正是太阳的颜色——晨光蜜琥珀 `#EF9F27`，名字和视觉是一套的。

App 启动器上显示「逐日」——面向家里人的日常使用；SUNWARD 用在代码仓库、文档和对外场合。

太阳每天升起，从不问你跑多快，只问你今天来不来。
**这就是这个 App 的立场。**

## 一、一句话主张

> # 不比快慢，只问今天。

tagline：**每天一点，一年很远。**

它同时解释了产品结构：首页是「日」，报告是「周 / 月 / 年」——年度报告的意义，
就是每日微小的总和。

## 二、四条原则

### 原则一 · 每天是单位，公里是结果

界面最该回答的问题是「**今天动了吗**」，而不是「今天还差几公里」。
公里数是**结果**，不是**成绩单**。

**落地表现**

- 首页「本周节奏」的进度 = 动了几天 / 7 天，不是 公里 / 30 km
- 报告页主卡的大数字 = 动过的天数，距离退为副信息
- 记录页月度卡的大数字 = 本月动过几天
- 「较上期」比的是**动过的天数**，不是里程

### 原则二 · 完成即满分，不制造欠账

「还差 29.9 km 达标」是**欠账制**。家里长辈跑两天，看到自己欠了一堆账，
最可能的选择是干脆不跑了。

**落地表现**

- 全站不再出现「还差 / 达标 / 目标进度」这类欠账措辞
- 「连续运动 N 天」（断了归零）→ 改为「**累计运动 N 天**」（从不归零）
- 进度条文案是「已动 5 天，共 7 天」，不是「距目标还差 23 km」
- 一天都没动时，文案是「今天还没动，出去走走吧」，不是指责

### 原则三 · 说人话，不说行话

「配速 5'49"」「节奏跑」「训练构成」是竞技跑者的词汇。
给家人做，就该是「每公里约 5 分 49 秒」「常跑」「运动构成」。

**落地表现**

| 行话 | 改成 |
|---|---|
| 配速 / 平均配速 | 每公里约 |
| 分段配速 | 每公里用时 |
| 训练已完成 | 今天也动了 |
| 训练构成 | 运动构成 |
| 轻松跑 / 节奏跑 / 长距离 | 慢走 / 常跑 / 远足 |
| 连续运动 | 累计运动 |
| 本周战报 | 本周战报（保留，不拗口） |

**字号下限 11sp**：原来全站有 108 处 8sp/9sp 的标签，长辈根本看不清。现在已全部提到
11sp 以上（`tools/bump_font_size.py` 可重复执行）。

### 原则四 · 不做裁判，只做记录

无数据源就不显示，绝不造假数字——这条已经做到了，现在把它讲明白。

AI 观察的语气必须是**描述**，不是**评判**：

- ❌「还差 10.2 km 达标，安排一次轻松跑就能补上」——这是裁判
- ✅「这周动了 5 天，一周里有好几天在动，这就很好」——这是记录

## 三、判定方法

拿到任何一个新需求 / 一句新文案，问三个问题：

1. **它是以「天」为单位，还是以「公里」为单位？** 后者要往前提。
2. **它会让用户觉得「欠了什么」吗？** 会的话就要改写。
3. **家里长辈能看懂这句话吗？** 看不懂就要换词。

三个问题有一个不通过，就先别做。

## 四、刻意不做的事

| 不做 | 原因 |
|---|---|
| 排行榜 / 好友 PK | 一比较就回到「快慢」，与主张冲突 |
| 「连续 N 天」断签提醒 | 断签提醒本质是惩罚 |
| 里程目标 / 配速目标 | 欠账制的来源 |
| 未达标的红色警示 | 红色 = 批评，家人不需要 |
| 社交动态 / 点赞 | 这是数据本，不是朋友圈 |

## 五、已知未做（属于功能，不属于理念）

- **家里不止一个人用**：头像写死是 `K`，「今日建议 出门走走 · 3.0 KM」对所有人一样。
  真正「给家人做」迟早要支持「这是谁」+ 按各自情况给建议。
- **长辈模式**：本轮明确不做。字号下限已提到 11sp，但如果爸妈仍然看不清，
  再做独立的「大字模式」开关。

## 六、视觉基调（2026-10 定稿为暖色浅色）

浅色暖底（`#F1EFE8`）+ 蜜琥珀（`#EF9F27`）+ 深琥珀（`#854F0B`），大字重、硬朗。
主题重设计取自启动图标同一套朝阳金色系（方案三·蜜琥珀，见 `design/explore/color-schemes.html`
与 `design/explore/component-styles.html`，探索样稿不作验收基线）；深底荧光绿是早期探索方向，已放弃。
名字与视觉并不冲突：**逐日**是安静的名字，配硬朗的视觉，反而显得不废话。
周节奏卡按「今天动了吗」显示当日运动时长，周一至周日七色方柱、当日强调（规格见样稿 §02）。
