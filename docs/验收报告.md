### 计划外偏差（4 项，均已记录，不影响范围）

| # | 偏差 | 原因 | 影响 |
|---|---|---|---|
| D1 | 用 `sdkmanager.bat` 而非新版 `android.exe` | cmdline-tools 16111833 已将 sdkmanager 标记弃用，替代品 `android.exe` 启动即报 `Failed to create bin dir / 拒绝访问 (os error 5)`——它要在工作区外建目录，被 DSH 沙箱拒绝 | 无。`sdkmanager.bat` 功能完整（版本 `1.0.16625370`） |
| D2 | 包名用**斜杠**格式 `platforms/android-36`，不用分号 | `sdkmanager.bat` 是批处理文件，PowerShell 传入的 `'platforms;android-36'` 被 cmd 按 `;` 拆成两个参数，报 `Package platforms not found` | 无。M1 起沿用斜杠格式 |
| D3 | **额外**安装了 `platforms/android-37.0` 与 `build-tools/37.0.0`（计划 §7 M0 只写了 36） | AGP 9.4.1 可能要求 compileSdk 37；预装可避免 M1 中途再下载 | 正向：M1 不会因缺组件卡住 |
| D4 | 设置了 `ANDROID_USER_HOME=D:\a\tools\android-user`、`ANDROID_PREFS_ROOT=D:\a\tools\android-prefs`；并 `git config core.autocrlf false`、`core.quotepath false` | 前者避免 SDK 工具写 `%USERPROFILE%\.android` 被沙箱拒绝；后者避免 CRLF 转换破坏 `gradlew` shell 脚本、并让中文文件名正常显示 | ⚠️ **M1 构建时必须同样设置这两个环境变量**，我会写进构建脚本/文档 |
